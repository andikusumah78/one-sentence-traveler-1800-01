Entry for the make.fun bounty
[One Sentence for a Traveler from 1800](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb)
— one sentence (162 characters) explaining the modern internet to
someone arriving from 1800, built only from things they already know:
a library, a post office, a letter, a book, a great hall.

## The sentence

> Imagine every library and post office in the world joined into one great hall, where any letter you write is answered at once and any book opens before your eyes.

## Run it

```sh
python3 main.py
```

`main.py` (pure Python 3.13 stdlib, no network, deterministic) writes
exactly that one sentence to `/output/entry.txt`.
